# Simple Python Addition Script

This is a basic Python script that defines a function `add_numbers` to add two numbers. The function takes two arguments, adds them, and returns the result.

## How it works:
1. Define a function `add_numbers(num1, num2)` that returns the sum of `num1` and `num2`.
2. Print the result when the script is executed.

### Example:
The script adds `5` and `3` and prints the result: `8`.
